# GPU Raymarcher
I made my own little custom shadertoy-ish thing a while back with help from [LearnOpenGL](https://learnopengl.com)<br>
Both this project and the GPU black hole renderer are made with that as the basis.<br><br>
It's an infinite terrain which you can explore. Performance is pretty shit, it runs fine on my GTX 970 at 1080p.<br><br>
I definitely want to do more raymarching stuff like this in the future, very unique technique with a bunch of possibilities and unique looking visuals.<br><br>

Infinite terrain, with some REALLY shitty "transitions" between desert and regular land.<br>
Beautiful clouds which are really raymarching artifacts<br>
Ugly wave reflections
