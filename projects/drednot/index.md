# Drednot stuff
[Drednot](https://drednot.io/) is probably one of my all-time favorite games.<br><br>
Over my years of playing drednot, "I" have made an array of QoL tools, and some tools that went a bit past QoL. Most of these were vibecoded, I've stopped "vibecoding" now.<br>I'm keeping some of those vibecoded tools here because they can be genuinely useful.<br><br>

[ignore.js](/projects/drednot/ignore.js) - basically just a block function. Don't like somebody? Block them and you won't have to deal with them.<br>
[boilerplate.js](/projects/drednot/boilerplate.js)* - boilerplate to read/write to and from the chat/MOTD. Create some minigames or something.<br>
[antiafk.js](/projects/drednot/antiafk.js)* - Simple anti AFK script. Sends a chat message every 30 seconds. Keep the tab in focus for best results.<br>
[Econonmy utils](/projects/drednot/econ) - Econ log utility. Very useful, pretty easy to use. Dogshit codebase though, you'd be better off creating your own tool from scratch rather than building on top of this.<br>
[tools](/projects/drednot/tools) - Some web tools for drednot. Includes a blueprint order grouper, and a tool to quickly program your printer.<br>


\* Don't forget to set your username in the script. I should've added a way for that to be detected automatically. Whatever.
