# Drednot tools

Directory of some random ass web based tools I made for this game<br>
The pages listed here use [SkySea's goated dsabp library](https://github.com/Blueyescat/dsabp-js).

 - A [ship DSA to NEMO's ship printer configuration converter](/projects/drednot/tools/printer).
 - [Simple DSA editor](/projects/drednot/tools/counter), not as advanced or complete as the one SkySea made. It can view the build cost and change blueprint command order.
 - [Blueprint diff](/projects/drednot/tools/diff): subtract a damaged ship's blueprint from the original to get a blueprint of just the missing stuff.
